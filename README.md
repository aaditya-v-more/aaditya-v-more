## Recent projects

### [Claude Graft](https://github.com/aaditya-v-more/claude-graft)

A macOS app for running multiple Claude Desktop accounts with separate profiles, shared Claude Code history, and live usage indicators. Swift, SwiftUI, and a Homebrew cask. **200+ release downloads.**

[Demo and installation](https://aaditya-v-more.github.io/claude-graft/)

### [Claude Ollama Proxy](https://github.com/aaditya-v-more/claude-ollama)

A macOS launcher and local proxy for Claude Desktop and Ollama: accurate model context windows, request pacing, and retries that stop before a streamed response begins.

[Demo and installation](https://aaditya-v-more.github.io/claude-ollama/)

### [WorldQuant Orchestrator](https://github.com/aaditya-v-more/worldquant-orchestrator)

A Python library and CLI for research workflows over the WorldQuant BRAIN API, with data discovery, backtesting, a SQLite audit ledger, and explicit confirmation before submission.

### [DMR - devin-model-router](https://github.com/aaditya-v-more/devin-model-router)

Per-message model routing for Devin CLI through the Agent Client Protocol, using expected cost and configurable reliability targets. The idea came from Anil Maryala, with collaboration from Kartik S.
